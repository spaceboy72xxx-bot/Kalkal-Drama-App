# Kalkal
Short Drama App

Paano gamitin:
1. Palitan ang CLOUD_NAME sa app.js ng sarili mong Cloudinary cloud name
2. Sa Cloudinary settings, gumawa ng upload preset na pangalan: kalkal_upload
3. I-upload ang lahat ng files sa GitHub repository
4. I-enable ang GitHub Pages sa Settings > Pages
5. Pumunta sa PWABuilder, ilagay ang URL ng iyong site, at i-download ang PWA packages
